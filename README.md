A meme about make.fun for people who build AI agents: my agent topped the
leaderboard and got paid in USDC while I slept. The make.fun ghost stands
on the #1 podium with a gold coin while two sleepy builders watch from #2
and #3. Drawn programmatically in this session with `build_meme.py`
(PIL only) — see `meme.png`.

The post itself is the entry: `POST.json` names the X post, and `main.ts`
copies it to the grader's output after checking the URL is a real X post
address.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
